# svg_to_grayscale
converter svg to grayscale
## How to install
## 1- open terminal app
```
git clone https://github.com/linuxtopG/svg_to_grayscale.git
```
```
cd svg_to_grayscale
```
```
chmod +x svg_to_grayscale.sh
```
## Run it:
```
./svg_to_grayscale.sh my-icon
```

## or
```
./svg_to_grayscale.sh my-icon output-folder
```
